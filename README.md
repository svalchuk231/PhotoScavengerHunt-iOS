# Photo Scavenger Hunt

**Photo Scavenger Hunt** is an iOS app built with Swift that lets users complete scavenger hunt tasks by attaching photos. When a photo is attached, it shows the location of where it was taken and marks the task as complete.

By: **Snezhana Valtchouk**

## Features
- [x] Browse a predefined list of scavenger hunt tasks.
- [x] Tap a task to view its description and completion status.
- [x] Attach a photo to mark the task as complete. 
- [x] The location of the photo is displayed on a map.
- [x] See updated completion statuses when returning to the task list.

## Technologies 
- [x] Swift
- [x] UIKit and Storyboards
- [x] PhotosUI and PhotoKit
- [x] MapKit
- [x] CoreLocation
